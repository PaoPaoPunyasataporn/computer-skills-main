7. THE AI COURSE GROWS UP: 6 → 10 MODULES ON THE EXPERIENCE AI ARC
   [9 August 2026]
================================================================================

--- Why -----------------------------------------------------------------------

Every AI module so far simulated a chatbot screen and taught how to drive it —
buttons, tokens, prompts, tutors. That is the middle of an AI education, not the
start of one. A kid who finishes it can prompt well but has no model of WHY the
thing behaves the way it does, so course was restructured on the six-lesson
foundation arc of Experience AI (Raspberry Pi Foundation × Google DeepMind —
right age band, built offline-first for their Kenya deployment, structure worth
stealing): what AI is → how machine learning learns from data → bias in data →
generative tools → real-world applications → applied challenge.

--- Four new games fill the missing layers ------------------------------------

  ai6-model-trainer   "ครูฝึก AI"          The kid IS the trainer: label cat/dog
                                          examples, train, watch the model pass or
                                          fail test items, hunt planted bad labels,
                                          and fix a model that only ever saw red
                                          apples. Data → training → prediction,
                                          garbage in → garbage out.
  ai7-bias-detective  "นักสืบอคติ AI"       Three cases (fruit sorter vs green
                                          apples, face-gate vs shorter students,
                                          voice assistant vs regional accents):
                                          observe the unfairness, diagnose the
                                          skewed training table, fix the data,
                                          watch the fairness bars level out.
  ai8-ai-in-the-world "AI รอบตัวเรา"        Match real systems (maps, X-ray reader,
                                          crop doctor, flood warning, translator)
                                          to what they were trained on, then judge
                                          six scenarios: smart use or be careful
                                          (deepfakes, over-trust, privacy).
  ai9-ai-quest        "ภารกิจนักออกแบบ AI"   Capstone in Experience AI's "AI Quest"
                                          style: design the school's recycling-
                                          sorter end to end — pick the problem,
                                          pick the data, read a per-class accuracy
                                          table, fix a bias case, choose the
                                          responsible-use rules, launch it.

Course order in lib/content.ts is now concepts (0-2) → tools (3-7) → world +
capstone (8-9); the old ai1-ai5 games kept their files but their "โมดูล N" chips
were renumbered to 3-7. AI_CURRICULUM.md was rewritten around this arc and
mapped to the UNESCO AI Competency Framework for Students — the same citable-
backbone move as the DigComp mapping on the literacy side. The previous
AI-Class-ASEAN-based draft lives on in git history; its ethics/privacy themes
were folded into modules 2, 8 and 9.

Per the rule from entry 6 ("run the audio build after adding any new Thai
text"), the ~350 spoken strings in the four new games were recorded with
gen-audio-edge.mjs — so the new modules speak the good Edge voice from day one
and are exempt from the pending old-voice migration.

================================================================================
6. THE SPEAKERS NOW SPEAK REAL THAI · 2-STAR PARTY · SHORTER GAME CARDS
   [12 July 2026]
================================================================================

--- Why some speakers sounded wrong ------------------------------------------

`dlf.speak(text)` plays a pre-recorded Thai MP3 when one exists for that exact
string, and only falls back to the browser's speech engine when it doesn't.

This machine — and most Thai school Windows machines — has NO Thai voice installed
(only English David/Zira). So every speaker whose text had no clip was being read
in an English accent. Those were the ones that "used the backup TTS".

The clip maps were generated before much of the content existed, so the gaps were
big: the boss fight had clips for only 34 of its 92 answer options.

Fixed in two halves:

1. Every speaker now says text that is actually recorded. Where a speaker had been
   given an invented paraphrase ("ปุ่มย้อนกลับ") it now says the control's real
   on-screen label, which is what got recorded.

2. The missing clips were RECORDED. `scripts/gen-audio.mjs` finds every Thai string
   a game can speak, synthesises the ones with no clip, and embeds them in the same
   map under the same key scheme. 560 new clips across the 9 games.

   The React side had no clips at all (its speakers were pure browser-voice, so the
   competition quiz and the exit dialog were gibberish on a Thai-voice-less machine).
   `scripts/gen-audio-app.mjs` records those 301 strings into public/audio/ with a
   manifest; lib/speak.ts now plays the clip and only falls back to the browser voice
   for a string with no recording.

   Both scripts are idempotent and cached — re-running costs nothing. Run them after
   adding any new Thai text, or its speaker will fall back to the browser voice again.

   node scripts/gen-audio.mjs        # the 9 games
   node scripts/gen-audio-app.mjs    # the React app (competition, dialogs)

   `node scripts/check-speakers.mjs` audits it: it reports any speaker whose text has
   no clip. It currently reports zero.

   A bug worth naming: the first extractor pass used a naive regex that truncated any
   string containing the other kind of quote — so 21 quiz questions like
   'มีอีเมลจาก "ธนาคาร" บอกว่า…' were silently skipped. Both scripts now use a proper
   string-literal matcher.

TRADE-OFF, PLEASE READ: the clips are embedded as base64, so the games got much
bigger — the boss fight is now 17.6 MB, unit5 15.2 MB. That is fine over a LAN or a
decent connection, but on a slow classroom link the first load of a game will be
noticeably slower. If that bites, the fix is to move the clips out of the HTML into
public/audio/ like the React side already does, and have dlf fetch them on demand.

--- 2 stars now gets the party ------------------------------------------------

dlf.bigCongrats fires confetti + the cheering clip at 2 stars or more (was 3).
1 star still gets the quiet well-done screen.

--- Guided games always award 3 stars -----------------------------------------

Where the child is walked through and cannot really fail, the game now just gives 3
stars on completion instead of grading them:

  unit1 Learn mode      (read all the parts)
  unit2 Mock Desktop    (step-by-step missions)
  unit3 keyboard lessons (drills only advance on the correct key)
  unit4 browser quest   (missions only advance on the correct action)

Still genuinely graded, because a child really can do worse: unit1 Quiz/Memory/Care,
unit2's timed click arena, unit5 (lives), unit7, unit8, unit9, and the boss fight
(full pass = 3, conditional pass = 2).

--- Shorter game cards --------------------------------------------------------

On a category page each game card reserved a footer row that used to hold the
completion star. With that indicator gone the row was empty space. The play button
now sits in the header row and the card is only as tall as its content
(components/LessonApp.tsx + a `.gamecard` block in app/globals.css).
